This release contains the standalone Lua implementation developed for
ROXASBrandon. External memory maps were used as references; no external library
is bundled or required. The item and orb range patches were derived by
inspecting the supported Steam executable and verified against the running
game. Other Treasure Magnet mods were researched, but their scripts are not
included in these packages. No game binaries, assets, or saves are distributed.
